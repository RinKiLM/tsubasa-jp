# 言翼 Tsubasa · 日语语法结构自习室

> **把零散语感，组装成清晰的日语语法体系。**  
> 面向中文母语者的轻量级跨端日语语法电子教材与动词变形道场（PC / iPhone PWA）。

**在线使用**：[https://rinkilm.github.io/tsubasa-jp/](https://rinkilm.github.io/tsubasa-jp/)

---

## 为什么做「言翼 Tsubasa」？

很多中文母语者在自学日语时会卡在同一个阶段：五十音已经滚瓜烂熟，看番看日剧、去日本旅行也有一定语感，但真正想系统学语法时却很难找到顺手的工具：

- 纸质教材厚重、前期节奏慢，通勤或在外面不方便随时翻看；
- 游戏化刷题软件进度缓慢，很少从底层把“为什么这样变形”讲透；
- 欧美口碑极佳的结构化语法资源（如 Tae Kim、Cure Dolly、Bunpro）以英文为主，既多了一层语言转换，也没能发挥中文母语者的汉字优势。

**言翼 Tsubasa**（取自「言の翼 / ことばのつばさ」）尝试把**结构化语法拆解**、**高频变形肌肉记忆训练**和**清爽的移动端阅读体验**结合在一起，从「会五十音、零系统语法」出发，稳步迈向 **日本自由行无障碍 + JLPT N1**。

## 核心功能

### 1. Stage 0 语法破冰骨架（8 节互动课）
系统打通日语底层语法框架：
- **01–04 课**：SOV 语序与三大句型、`は` vs `が` 聚光灯模型、7 大核心格助词地图、两类形容词修饰与变形；
- **05–08 课**：动词三大分类法、礼貌体与普通体双向切换、万能 `て形` 音便规律、定语从句与 `の` 名词化。

每课包含**一句话底层逻辑**、**句子积木公式 / 对比表**、**中文母语者避坑指南**、**日常旅行 & JLPT 双轨例句**以及**单选 + 语序拼句课后自测**。

### 2. 日系极简阅读辅助
- **振假名（Furigana）一键开关**：入门显示汉字注音，进阶隐藏测认读；
- **四色语法结构高亮**：直观区分主题/主语、助词、修饰语与谓语变形；
- **中文译文折叠 & 日语朗读**：支持 `0.75x / 1.0x` 语速切换；
- **双主题护眼排版**：支持「和纸浅色」与「深夜靛蓝」切换。

### 3. 动词 & 形容词变形道场
- 内置 44 个高频核心词（完整覆盖五段 9 种词尾、一段、不规则动词，以及 `帰る / 行く / いい / きれい` 等高频陷阱词）与实时变形推导引擎；
- 支持 **速选模式**（手机单手通勤刷题）与 **拼写模式**（平假名或罗马音自动转写）；
- 可按词类、目标形态（`ます / ません / ない / て / た / 可能 / 意志`）及「只刷陷阱词」自由组合练习，答错即时展示变化步骤。

### 4. 错题复习本 & 跨端无损同步
- 课后自测与变形道场答错的题目自动收入错题本，掌握后一键消掉；
- 支持 **手机扫码 / 魔法同步链接智能合并**（无需注册即可在 PC 与 iPhone 之间无损合并课程进度、最高分、打卡天数与错题），也支持可选的 Supabase 实时云同步；
- 内置 **邀请内测与结构化反馈中心**，方便分享给朋友体验并回收改进建议。

## 快速使用

- **电脑端**：直接访问 [https://rinkilm.github.io/tsubasa-jp/](https://rinkilm.github.io/tsubasa-jp/)；
- **iPhone / 手机端（推荐）**：用 Safari 打开上述网址 → 点击底部「分享」→ 选择 **「添加到主屏幕」**，即可获得全屏 App 体验并支持离线阅读；
- **跨设备同步**：在「错题与同步」页生成同步二维码或魔法同步链接，另一台设备打开后选择「智能合并」即可保留两端进度。

> iPhone 提示：若点击例句朗读没有声音，请确认机身侧面的物理静音开关未开启。

- **技术栈**：React 19 · TypeScript · Vite 6 · Tailwind CSS v4 · `vite-plugin-pwa` · Lucide React · QRCode
