# 言翼 Tsubasa · 日语语法结构自习室

> **把零散语感，组装成清晰的日语语法体系。**  
> 一款面向中文母语者、专为 PC 与 iPhone 跨端自学打造的轻量级 **PWA 日语语法电子教材与动词变形道场**。

[在线开始学习](https://rinkilm.github.io/tsubasa-jp/)

---

## ✨ 为什么做「言翼 Tsubasa」？

市面上大多数日语自学方案存在两个痛点：
- 传统纸质教材厚重、节奏偏慢，不适合在通勤或咖啡馆随手翻看；
- 通用游戏化软件（如多邻国）碎片刷题进度缓慢，无法系统讲清日语语法底层逻辑；
- 欧美口碑极佳的结构化工具（Bunpro / Tae Kim / Cure Dolly）几乎全英文界面，中文母语者反而浪费了天然的汉字优势。

**言翼 Tsubasa** 借鉴了结构派语法指南（Tae Kim / Cure Dolly / Yokubi）的逻辑拆解思维、Conjugation Drill 的高频变形训练与现代移动阅读体验，帮助你从「熟练五十音 + 零系统语法」出发，稳步迈向 **日本自由行无障碍 + JLPT N1**。

## 🚀 当前功能（MVP v0.1）

1. **Stage 0 语法破冰骨架（8 节完整互动课）**
   - 涵盖：SOV 语序与三大句型、`は` vs `が` 聚光灯模型、7 大核心格助词地图、两类形容词修饰与变形、动词三大分类法、礼貌体与普通体双向切换、万能 `て形` 音便规律、定语从句与 `の` 名词化。
   - 每课配备：**核心底层逻辑总结**、**句子积木公式**、**中文母语者避坑指南**、**日常旅行 / JLPT 双轨例句**、**课后单选 + 语序拼句自测**。
2. **沉浸式阅读辅助**
   - 全局 **振假名（Furigana）** 一键开关、**语法结构色块**（主题/助词/修饰/谓语四色区分）、**中文译文折叠**、**日语朗读与变速（0.75x / 1.0x）**、**和纸浅色 / 深夜靛蓝双主题**。
3. **动词 & 形容词变形道场**
   - 内置 44 个高频词（覆盖五段 9 种词尾、一段、不规则、`いい / きれい / 帰る / 行く` 等高频陷阱词）与实时变形引擎。
   - 支持 **速选模式**（手机单手友好）与 **拼写模式**（支持平假名或罗马音自动转换），每题附详细变化推导步骤。
4. **错题复习本、跨端智能同步 & 朋友内测中心**
   - 自测与道场错题自动归集，支持一键标记「已掌握」；
   - 支持 **零配置手机扫码 / 魔法同步链接智能合并** 与 **可选免费 Supabase 账号实时云同步**（出门在外 4G/5G 无损保留两端学习进度）；
   - 内置 **邀请朋友内测二维码 / 微信邀请文案** 与 **结构化内测反馈中心**（自动附带设备与页面上下文，支持复制发微信、GitHub Issue 及云端直存）。
   - 完整上线、云同步与内测指南见：[DEPLOY_AND_TEST_GUIDE.md](./DEPLOY_AND_TEST_GUIDE.md)。
5. **PWA 跨端体验**
   - 在 iPhone Safari 中点击「分享 → 添加到主屏幕」即可作为独立全屏 App 使用并支持离线访问。

## 🛠️ 本地开发与免费部署

### 本地启动
```bash
npm install
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 一键免费部署到 GitHub Pages（让 iPhone 随时访问）
仓库已内置 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)：
1. 将本项目推送到你的 GitHub 仓库的 `main` 分支；
2. 打开仓库 `Settings → Pages`，将 `Source` 设为 **GitHub Actions**；
3. 等待约 1 分钟部署完成，即可获得永久免费 HTTPS 网址（电脑与 iPhone 均可直接打开并添加到主屏幕）。
